## 1. 总原则（[现状] 已具备的工程事实）

- **本地优先**：存档/记忆默认只存本机，加密保存（Windows 用 DPAPI；浏览器用 AES-GCM + 不可导出 IndexedDB key；加密不可用时**拒写** fail-closed，`src/pet/crypto.ts:45-92`）。
- **famling 无云对话**：famling 桌面端当前构建无自由 LLM 对话调用（无 `chat/completions` call site；roleplay 仅本地模板）；`dsh-famling` 插件是**另一产品**，其聊天经 DSH Host 发往用户配置的模型供应商（见 §2A）。TTS/ASR 仅在用户显式启用并同意后调用。
- **遥测默认关**：默认 0 上报；Sentry 仅 aquarium 入口 opt-in。
- **不训练**：本项目当前**不使用**用户对话/语音/记忆数据训练模型（内部政策；对外承诺须律师定稿并在改变前重新告知同意）。
- **最小化**：ASR 文本不落盘、不写日志用于分析；审核留痕方案见 [工程待办]。

## 2A. 两端边界：famling 桌面端 vs dsh-famling 插件（2026-11-19 代码事实）

> 两产品共用同一份统一使用限制（[USE-RESTRICTIONS-2026-11-19](/legal/USE-RESTRICTIONS-2026-11-19.md)），但**数据流与能力不同**，不得用一份文本互相套用或混写。

| 项 | famling（本仓桌面应用） | dsh-famling（DSH 客户端插件，另一仓） |
|---|---|---|
| 自由 LLM 文本聊天 | **无**：roleplay 仅本地模板/声明/设定，不伪造聊天引擎 | **有**：`op:"chat"` → DSH Host `ctx.llm.stream`，provider/model 来自 DSH 默认模型或插件 Config；输入文本会发往对应模型供应商 |
| 角色扮演/情感陪伴 | 不提供（roleplay 仅本地模板；18+ 门禁、内容须全年龄适宜） | 不提供（插件文档明确“不提供角色扮演/情感陪伴；聊天为普通 AI 回复”） |
| TTS | DeepSeek TTS（baked 42 WAV + 云 TTS，用户自带 key）；应用内独立同意 | 浏览器/系统 `speechSynthesis`；插件设置内独立同意；不调用 DeepSeek TTS |
| ASR | DeepSeek ASR，经 Tauri 代理；应用内独立同意，拒绝不录音/不上传 | 浏览器 `SpeechRecognition`；音频可能发送给浏览器厂商，插件不接收音频文件；独立同意 |
| Advisers Pet Brief | 只读本机 `~/.advisers/pet-brief.json`，不上传/不入 TTS/LLM | 只读本机 `~/.advisers/pet-brief.json`（投影计数与少量标题），不上传/不入模型/语音 |
| 本机持久化 | 存档/记忆加密；同意/审计/导入摘要 localStorage 明文；TTS 缓存+quota | localStorage 设置 + 一次性首启确认 + TTS/ASR 同意（当前无版本/哈希；插件 LEGAL 已注明待升级）；设置内“清除本机设置与同意”可删除 `dsh-famling/*` 键 |
| 网络 | 云 TTS/ASR（同意后）、导入公开 DeepSeek 分享、Sentry（默认关）、远程市场（当前默认不联网） | 同源 `/api/famling/bridge` → DSH Host（聊天/简报/提醒）；插件无遥测/服务端日志 |
| 账号/遥测/服务端 | 无账号；遥测默认关（aquarium opt-in） | 无账号/无遥测/无服务端日志/无 API Key |

**对外写法**：famling 可写“无自由 LLM 对话”；**插件不能写“不提供自由 LLM 对话”**，只能写“不提供角色扮演/情感陪伴，聊天为普通 AI 回复，输入会发给模型供应商”。插件条款与责任分层以插件仓 `docs/LEGAL-NOTICE-2026-11-18.md`（2026-11-19.2，适用插件 0.10.2）为准；缺口与复核项见律师复核清单 §3-9。

## 2B. 远程内容市场数据流（当前默认离线；未来启用前须更新本政策）

- **[现状] 默认不联网**：`src/pet/content-market.ts` 的 transport 默认为 null，无全局 `fetch` 回退；未注入 transport 时 `configured:false` 且返回稳定失败码 `transport-unavailable`，构造/导入均**零请求**。famling 内容中心「市场」tab 只显示“服务器未配置 · 默认不联网”，不展示伪造商品。
- **[目标/未来] 启用后的数据流（设计意图，未上线）**：仅当宿主（未来 Rust 受控传输）显式注入 transport 且用户主动点击“刷新市场目录”时，才 HTTPS 拉取签名目录（`catalog.json`）与内容包 zip；客户端做 Ed25519 验签、逐文件 sha256、防回滚（serial/storage）；内容包安装到本机。无账号、无遥测；承载传输会向服务端暴露标准 HTTP 元数据（IP/UA 等），服务端隐私做法须在启用前另行披露并更新本政策与商店申报。
- **不得**把“预留市场接口/占位 UI”写成“已上线市场/已联网/已合规”；启用联网前必须完成：隐私政策更新、传输边界评审（TS 不直接 `fetch`、由宿主受控传输）、发布门禁与商店 AI/数据申报。

## 3. 处理目的与范围

- **目的**：提供桌宠/工作助手功能（本地交互、存档、记忆、可选的云语音）；安全审核与合规留痕；计费提示（第三方费用由用户与服务商结算）。**不用于**广告画像、自动化决策、出售数据。
- **范围**：仅本机数据 + 用户主动启用的云语音请求；不读取通讯录/位置/剪贴板/其他应用数据（Advisers 仅在你开启后读取其公开约定的 brief 文件，见 §2-7）。
- **单独同意**：语音音频可能含声纹等**敏感个人信息**，拟按 PIPL 第 28–29 条单独同意；**ASR 独立声明+门禁已实现**（`src/pet/consent/asr.ts`、`gate.ensureAsr`）：`getUserMedia` 前必须单独确认，TOS/TTS 同意不能替代，拒绝/错误 fail-closed。**TTS 独立声明+按会话/配置再次确认已实现**（`tts.ts`、`gate.ensureTts`）。TTS/ASR 第三方留存、跨境与 DPA 仍 [TBD]，须以其书面披露为准。

## 7. ASR 专项（[现状] 独立声明+单独同意已实现；仍缺开关/配额/供应商披露）

[现状 2026-11-19 代码核对]：TOS 通过后才进入 ASR 流程；**ASR 独立声明**（`terms.ts` `ASR_SECTIONS`，`ASR_VERSION=2026-11-17.3`）与单独同意已实现（`gate.ensureAsr` / `main.ts beginTalkWithAsrConsent`）：未确认不调用 `getUserMedia`、不录音、不上传；拒绝/错误 fail-closed；确认按“会话 + ASR 配置签名”生效（provider/单次上限/WAV 上限/会话变化需重新确认），不持久化为永久豁免；TOS/TTS 同意均不能替代。成功确认后才 `grantHostVoiceConsent('asr')` 并由 Rust 代理上传 `api.deepseek.com/v1/tools/asr`（单次 ≤60s、WAV ≤8 MiB）；本机不保存录音与识别原文。

[仍为工程/合规缺口]：
