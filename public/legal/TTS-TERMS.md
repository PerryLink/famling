## 2. 使用前提

1. **自带账户**：用户必须使用自己的 DeepSeek 账号/API Key 生成语音；不得共享、转售、出借 key。
2. **费用自担**：TTS 调用按服务商计费规则产生费用；本项目不代付、不返还、不承诺额度。
3. **合规内容**：不得生成违法、侵权、仇恨、色情、未成年人性化、冒充真人、骚扰、隐私侵犯内容。
4. **AI 披露**：发布含 TTS 的音频/视频/直播时，必须显著标注“AI 生成语音”，不得伪装真人录音。
5. **禁止克隆**：不得使用真人声音样本、参考音频、声纹嵌入或任何克隆/模仿真人声音的能力；仅可使用服务商提供的合成音色。
6. **音源授权**：不得用影视/游戏/他人音频作为参考或素材；BGM/SFX 必须自有或获授权并登记 `THIRD-PARTY.md`。

## 2A. 启用、变更与再次确认（硬性，2026-11-17 追加）

TTS 不是“设置一次就永久跳过”的功能。以下每一次动作，应用都必须重新展示**短确认**（canon：`tts.enableConfirm` / `tts.changeConfirm`，见 [APP-DISCLOSURE-TEXTS](/legal/APP-DISCLOSURE-TEXTS.md)）并取得用户明确确认：

1. **首次启用** TTS（含 baked 预生成播放以外的实时/云 TTS）。baked 预生成播放仍属 AI 合成语音，AI 披露/首次提示按 §8 执行；本次只把预生成音频纳入包，未改应用内确认文本/版本（版本与 hash 以 `terms.ts` 当前 canon 为准）。
2. **每次重新开启**（用户关闭后再开）。
3. **切换 provider**（本地系统语音 ↔ 云 TTS；DeepSeek ↔ 其他）。
4. **切换音色/voice id**（如 `stella` → `tide` 或其他）。
5. **切换计费/额度设置**，或首次触发费用提示前。
6. **变更朗读范围**（如从“仅提示音”变为“朗读全部台词/对话”）。

确认文案至少包含：①“AI 合成语音，不是真人”；②“可能读错/断句/语气不自然”；③“文本将发送给 <provider>，可能产生费用，由你的账户承担”；④“隐私说明/服务商条款”链接。**不得默认勾选、不得隐藏关闭入口、不得以“不再提示”绕过后续变更确认**（首次确认可记住“已告知”，但启用/变更确认不可永久关闭）。

## 2C. ASR（语音识别）单独确认（2026-11-17.2 追加，P0）

语音识别是**独立于 TOS 与 TTS** 的单独同意：TOS 同意或 TTS 确认都不能替代 ASR 声明，ASR 确认也不能替代 TOS/TTS。当前实现事实（canon：`terms.ts` `ASR_SECTIONS`；运行时 `gate.ensureAsr` / `main.ts startTalk`）：

1. **默认不录音**：未确认 ASR 声明前，不调用 `getUserMedia`、不录音、不上传音频。
2. **范围**：按住说话单次最长约 60 秒；WAV ≤ 8 MiB；经本机 Tauri 代理上传至 `https://api.deepseek.com/v1/tools/asr`（用户自备 API Key，费用按其规则）。
3. **可能出境**：录音发往 DeepSeek（深度求索），可能构成跨境传输；供应商留存/处理地/是否训练**尚未书面确认（TBD）**，发布前补齐告知。
4. **本机处理**：不保存录音与识别原文；识别文本仅内存中用于当次交互，先经本地安全审核，不写入日志/存档。
5. **会话/配置绑定**：确认仅存内存、按会话+ASR 配置签名生效；配置变更或新会话重新确认；拒绝后同一配置不重复弹窗。
6. **当前能力**：无 ASR 日配额/费用提示（TTS 另有限额）；无监护人验证/未成年人模式；角色扮演 18+ 年龄门槛采用“自报出生日期”核验（非官方身份证核验，可被虚假自报/修改绕过）；发布前未补齐则不得宣传“语音输入”卖点（PRIVACY §7）。

## 8. AI 拟人化互动与语音的强制提醒（2026-11-16 追加）

依据《人工智能拟人化互动服务管理暂行办法》（网信办令第 21 号，2026-07-15 施行）及项目合规研究（`docs/research/AI-COMPANION-REGULATION-2026-11-16.md`）：

3. **roleplay 边界**：仅限**明确进入**的场景演练/非恋爱虚构；不得提供虚拟恋人/亲属；不得以亲密称呼、好感度、付费解锁关系诱导。
4. **18+ 角色扮演门槛与全年龄内容边界**：一般功能全年龄可用；roleplay/情感支持**仅限年满 18 周岁用户**（2026-11-17.5 用户拍板，首次启动须完成自报出生日期核验；非官方身份证核验）。内容必须全年龄适宜——禁止成人性内容、虚拟亲密关系、未成年人性化、自伤他伤、违法、诈骗与冒充，不得诱导依赖/付费关系；不得生成未成年人性化/亲密内容。未成年人保护、健康使用与危机资源仍适用。
5. **情感依赖**：不得诱导依赖、制造内疚/独占/错过恐惧；必须提供退出/关闭/清除记忆；发现依赖倾向应降级并提醒接触真人。
