## 0. 结论先行（14 条）

1. **桌宠不是蓝海，是成熟红海；但“低压力工作搭子”仍是窄空位。** 桌面常驻类已有 Rusty's Retirement（$6.99，英文评测 6,628 / 97%）、Spirit City（9,253 / 97%）、Desktop Mate（2M 下载、45 个 DLC）、Bongo Cat（英文 31,358 / 96%、2025-04 同时在线破 12 万）、VPet（中文 43,520 / 98%）、Wallpaper Engine（3,210 万份估算）。**用户已经被教育过“桌面上可以有东西”，但没有被教育过“桌面上可以有工作账本”。**
2. **成功者的共同点不是 AI，而是“低价/免费 + 零摩擦常驻 + 一个清晰场景”。** $3.99–$11.99 买断或免费 + 外观 DLC 是主锚；移动端是免费 + 广告/IAP/订阅；插件生态是免费。**AI 桌宠没有跑出同量级的商业样本**，而 AI 伴侣类正在被监管收紧（见 §9）。
3. **高口碑几乎都来自同一组词：低压力、无惩罚、可缺席、可爱即时反馈、可装饰/收集、便宜。** 差评则集中在：内容耗尽快、DLC/内购/货币卡点、性能与耗电、太被动/没互动、打卡/死亡/内疚、更新慢、AI 不真实。
4. **“内容型桌宠”衰减很快，“常驻工具型桌宠”更长寿。** Neko Atsume 2 上线两年后 Sensor Tower 估算仅约 7k 下载/$5k 月收入；而 Rusty's / Spirit City / Bongo Cat 靠“开着就有用/有反馈”维持高好评。**famling 应做后者：utility + presence，而不是内容季更。**
5. **Tamagotchi 的“照顾-死亡”循环是双刃剑。** 1 亿台出货证明 care loop 的情感强度，也留下“离几天就死/内疚”的口碑负担；腾讯 2026 年复活 QQ 宠物时**明确取消死亡机制**。famling 不应引入饥饿/生病/死亡/断签惩罚。
6. **Finch 验证了最强的留存机制：把现实任务绑定到虚拟关系上**（约 5M+ 下载、约 $30M ARR 报道、4.9 分 / 7.5 万条评分）。但它同时因订阅推销、重复任务被媒体批评。**famling 要学“任务→角色反馈”，不要学“关系→付费”。**
7. **DSH 生态是 famling 当前唯一低成本、高确定性的分发窗口。** deepseek-harness 约 283,515★（4 天 +2,632★），`topic:dsh-plugin` 约 32,605 个仓；`dsh-pet` npm 近 30 天 596,652 次、`dsh-whale-widget` 417,066 次。**但“鲸鱼娘/桌宠”已高度同质化**（dsh+pet 检索约 1,128 仓），famling 只有 1★，npm 仍是 0.0.1、近 30 天 488 次下载——**分发链路是当前第一瓶颈，不是产品概念。**
8. **famling 的差异化只能是“组合”，不能是单项。** 原创 OC（汀岚/塞尔凯克卷毛猫/金毛）＋ 96×96 像素规范（12 clip / 68 帧 × 3 角色）＋ 头/身/尾分区点击回话 ＋ 猫狗仅空心心理气泡、human 实心语音 ＋ 只读 Pet Brief ＋ 本地优先 ＋ 独立 Tauri 与 DSH 薄插件双形态。单项都能被复制，组合与“边界纪律”才是护城河。
9. **定位建议：不是“AI 伴侣/电子宠物”，而是“桌面角落的安静工作搭子（秘书皮）”。** 一句话：**“一个记得你要做什么、但不缠着你的像素同事。”** 三种形态是记忆点，工作简报与低打扰是价值点。
10. **三个最高优先动作（可直接采纳）**：① **修分发链路**——统一 0.8.x 版本、npm 从 0.0.1 重发、一行安装、插件市场/榜单、README GIF/截图与 QA 预览页；② **做 30 秒差异化 demo + 诚实声明**——三形象分区点击 + 只读简报 + “What it is / is not”，投 DSH/中文开发者社区；③ **建立本地 opt-in 指标与发布闸门**——首交互率、D1/D7、卸载理由，先验证再投美术/Steam。
11. **商业化建议：插件免费获客，独立版免费 beta → $9.99–12.99 买断；只卖外观 DLC（$2.99–4.99），不卖关系、不抽卡、不订阅、不广告。** 价格锚：Ropuka $3.99、Rusty's $6.99、Spirit City 常见折后约 $7、Chill with You $11.99、Wallpaper Engine $4.99；Desktop Mate 的 $14.99 角色 DLC 已引发 61% 英文好评的反弹。
12. **必须避免的宣称**：AI 真人/“像真人”、情感依赖/恋爱/“只有我懂你”、儿童向/教育向、付费解锁关系/亲密度、官方 DeepSeek/官方鲸鱼娘、开源（实际 PolyForm NC）、已发布/已合规、永久记忆/绝不忘记、医疗/心理/专业建议。**这些不是文案偏好，是监管与平台红线（§9）。**
13. **最大风险不是竞品，是“定位漂移 + 分发漂移 + 许可/法务未闭环”**：一旦接自由 LLM 情感陪伴，就进入中国《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行）与加州 SB 243 等监管范围；PolyForm NC 与 CC BY-NC-SA 限制社区与商业；当前法务仍有 16 个 strict blockers、AI 标识未闭环、隐私政策为草案。
14. **不要把“Desktop AI Robot Pets”硬件市场报告当作 TAM。** 市面上的“Desktop AI Robot Pets”报告（如 QYResearch）统计的是 Ropuka/Loona 类**硬件机器人**，与软件桌宠不是同一市场；本文因此不给“市场规模 X 亿”的伪精确数字，只给可比产品区间与可验证指标。

## 2. 竞品案例卡（任务指定 8 个 + 桌面类 6 个）

> 每张卡回答四件事：它是什么/怎么分发、口碑数据、用户喜欢什么/反感什么、对 famling 的启示。外部评价均为“公开可见样本”的归纳，不代表全量用户。

### 2.1 Shimeji（2009，桌面漫游的鼻祖）

- **形态/分发**：日本 Group Finity 的 Yuki Yamada 约 2009 年发布的 Java 桌面吉祥物，Windows；开源（原始 zlib 许可，社区 fork Shimeji-ee 为 New BSD）。**免费**，靠社区皮肤包生态传播；安卓端有借名独立应用（Digital Cosmos 的 Shimeji，含等级/XP/“蘑菇”货币，仅 Android）。
- **口碑/规模**：无中心化评分，但“Shimeji 皮肤包”是十几年的社区文化；英文 fork 仍在维护（2026-11-12 仍有 push）。
- **喜欢**：屏内自由爬行/掉落/坐边，真正“活物感”；皮肤包可自行制作；零成本；情怀。
- **反感**：Java 环境/兼容与性能问题；无 AI、无记忆、无工作上下文；皮肤质量参差；新系统上安装门槛高。
- **启示**：**“角色包生态”比“单角色”更长寿**；“会自己动、会贴边”的存在感是核心。famling 的 regions/behavior/动画契约有潜力做“角色包”，但 PolyForm NC 与当前无 mod 市场会限制这一点。

### 2.2 Neko Atsume（2014，低压力放置的全球样本）

- **形态/分发**：Hit-Point 的庭院放猫游戏；2014-10 上线，免费 + 小额 IAP；Apple Arcade 版「ねこあつめ+」2024-11 上线；续作 Neko Atsume 2 于 2024-10-20 上线。
- **规模**：首作 2015-06 约 550 万下载、2015-09 约 650 万；系列累计 **3,300 万+**（Neko Atsume 2 商店文案）。Sensor Tower 估算 Neko Atsume 2 近一个月约 **7k 下载 / $5k 收入**（2026-10 前后）——**续作热度明显回落**。
- **喜欢**（App Store 评论与 4gamer 评测）：不催、不惩罚、随时关；猫的细节与“放粮—离开—回来看猫”的仪式；低认知负担；可爱。
- **反感**：等待太长、无主动交互、很快“看腻”；没有目标/进度感；续作被指换皮。
- **启示**：**“不要求你在场”是桌宠的核心美德**；但纯被动 + 纯内容会快速衰减。famling 的“只读简报 + 分区点击”可以在不增加压力的前提下给出“回来有变化”。

### 2.3 Pou（2012，5 亿安装的大众市场）

- **形态/分发**：Zakeh（黎巴嫩）2012-08 Android / 2014-03 iOS；免费 + 广告/IAP；怪物式养成 + 小游戏 + 换装。
- **规模**：Google Play **5 亿+安装**、4.3 分；Sensor Tower 2024 Q3 样本显示周下载约 42–50 万、周收入约 $2–4k、WAU 约 1,400–1,600 万（区域/安卓口径，非全球）。
- **喜欢**（Common Sense Media 儿童评论）：可换装、小游戏多、可“照顾”一个依赖你的生物、上手简单。
- **反感**：角色“依赖玩家”带来负担感；广告/内购观感（不同地区差异大）；重复；儿童向设计引发家长对注意力/消费的担忧。
- **启示**：**儿童/家庭市场很大，但与 famling 的“成人工作搭子”定位互斥**；且会触发未成年人保护、广告合规与品牌风险。famling 应主动声明“非儿童向”，不做“宠物依赖你否则会难过”的叙事。

### 2.4 Finch（2020，把自我照顾做成虚拟宠物）

- **形态/分发**：Finch Care PBC 的 self-care 应用：完成喝水/散步/呼吸/情绪记录 → 养一只小鸟；免费 + 订阅（约 $50–70/年）；iOS/Android。
- **规模**：公开报道约 **500 万+下载、约 $30M ARR**（2026，另有约 $2,270 万美国年化收入口径）；App Store 4.9 分 / 75,762 条评分（英国区，2026-08）。
- **喜欢**（媒体与商店评论）：把“该做的事”变成“小鸟会成长”的即时反馈；情绪记录/呼吸有陪伴感；低门槛；对年轻女性用户尤其有吸引力。
- **反感**（Slate 2026-09 深度评测等）：免费版不断推销 premium；任务重复；把情绪管理“游戏化”可能让用户感到被操纵；对心理健康的承诺需要更谨慎。
- **启示**：**“现实任务 → 角色状态变化”是最强留存机制**，famling 的 Pet Brief/承诺回执应学这一点；但**不能学“关系付费”和“情感依赖”**，且要避免把“陪伴”说成“治疗”。

### 2.5 Spirit City: Lofi Sessions（2024，工作场景 + 装饰 + 收集）

- **形态/分发**：Mooncube Games 2024-04-08 上线 Steam；买断（常见折后约 $7）+ 6 个 DLC（All Aboard $7.99）；2025-08 加入 Lofi Girl 大家庭。
- **规模**：英文评测 9,253（97%）、中文 2,460（95%）；steamrev 估算约 46.05 万拥有者、$331 万 gross / $119 万净收入（2025-08）；B 站官方号称 37.5 万份销量、11,660 条好评 98%（2025-08）。
- **喜欢**：番茄钟/任务清单 + Lofi + 房间装饰 + 精灵收集；“打开就开始工作”的习惯；有玩家 1,300+ 小时；DLC 提供新场景。**它证明“工作陪伴”可以卖钱且高好评。**
- **反感**：AFK 挂机 vs 认真玩的平衡；装饰/家具被游戏内货币卡住；DLC 付费墙；内容更新节奏；对“纯工具”用户偏重。
- **启示**：famling **不应在“内容量/装饰系统”上正面竞争**（打不过 46 万拥有者的内容库），而应用“更轻的角色 + 工作简报 + 桌面原生”切一个更小的位置。

### 2.6 Tamagotchi（1996，care loop 的原点）

- **形态/分发**：Bandai Namco 1996-11-23 发售；硬件（37 代 Tamagotchi Paradise 约 $50）+ 移动游戏（My Tamagotchi Forever）+ Tamagotchi Uni（TAMAVERSE 在线）。
- **规模**：**全球累计出货 1 亿台（2025-07-31）**；2025 年前 8 个月出货 1,000 万台（约占 30 年总量的 10%）；怀旧驱动复兴。
- **喜欢**（Amazon 评论）：怀旧、照顾的仪式感、随身设备、收集角色/代际；成年人把它当“减压玩具/身份配饰”。
- **反感**：照顾失误导致生病/死亡（有玩家“完美照顾 3 天仍死”）；体重/喂食机制复杂；电池/设备成本；对忙碌成年人不友好；像素屏与现代屏幕体验落差。
- **启示**：care loop 能建立强情感，但**“会死/会难过”是口碑与伦理负担**；famling 的“无分数、无好感、无签到、可缺席”方向正确，应写进产品原则并在文案中体现。

### 2.7 QQ 宠物（2005–2018；2026 复活）

- **形态/分发**：腾讯 2005 年推出的 QQ 内嵌桌面养成宠物；免费 + QQ 社交/付费道具；2007 年 **160 万同时在线**；2018-09 正式停运（服务器迁移/硬盘损坏、早期代码负责人流失、手游冲击、收入微薄）。2026-07 在手机 QQ 复活：3D 化、企鹅+狗+蒜头鹅、取消死亡、接入大模型做性格预设与“宠物日记”、社交“互踩续火花”。
- **喜欢**：桌面常驻的“同事感/陪伴感”；QQ 关系链带来的社交攀比与互动；怀旧；低门槛。
- **反感**：需要定时喂食/洗澡/打工，像打卡；后期内容老化；停运导致资产清零（对“养成资产”信任的伤害）；复活版被质疑卖情怀。
- **启示**：**分发与社交关系链 > 宠物本身**；单一桌宠产品的“运维经济”很容易死（QQ 宠物因收入微薄停运）。famling 必须把成本结构做成“本地优先、无服务器依赖”，并把“停运后数据可导出”当作信任承诺。

### 2.8 Wallpaper Engine（2018，桌面个性化平台）

- **形态/分发**：Steam $4.99 买断；动态壁纸 + Workshop UGC；安卓伴生 App 可传输壁纸。
- **规模**：英文评测 235,603（97%）、中文评测 435,697（96%）；steamrev 估算 **3,210 万份 / $1.60 亿 gross**（2025-08）；总评测约 91.7 万、98% 好评（估算）。
- **喜欢**：一次买断、极低价格、Workshop 内容近乎无限、桌面身份表达、性能选项多、持续更新。
- **反感**：部分壁纸耗电/占 GPU（移动版尤甚）；Workshop 内容质量与审核；创意工坊创作者无法直接通过 Steam 变现（社区讨论）；对老机器不友好。
- **启示**：“平台 + UGC”是桌宠品类里唯一被验证的规模化路径；famling 的角色包/美术规范未来可以走“官方精选 + 创作者分成”，但前提是**许可允许**（当前 NC 不支持）。

### 2.9 桌面类补充 A：Desktop Mate（2025，分发天花板 + DLC 反噬）

- **形态/分发**：infiniteloop 2025-01-07 上线；本体免费，官方授权角色 DLC（45 个，常见 $14.99）；Windows（macOS beta）。
- **规模**：约 200 万下载（2026-06 媒体报道）；英文评测 5,405（**61%，Mixed**）、中文 279（56%）、近 30 天 129（73%）。
- **喜欢**：3D 角色坐在窗口边/桌面互动；“官方 IP 角色”满足 ACGN 收集欲；零门槛。
- **反感**（VaporLens 2026-05 分析 + 评测）：DLC 太贵（“Overpriced DLC”占风险 16.2%）、移除自定义 VRM/无 mod、角色动作单一、更新慢、付费点过密。
- **启示**：**分发可以靠 IP 与免费本体冲起来，但高价 DLC + 封闭会迅速消耗口碑。** famling 若做付费，应优先“买断完整、外观低价可选”，不做 45 个 $14.99。

### 2.10 桌面类补充 B：Bongo Cat（2025，免费 + 梗 + 极简）

- **形态/分发**：Irox Games 2025-03-05 上线 Steam；免费 + 5 个外观 DLC；Windows；根据 2018 年推特“打鼓猫”梗改编。
- **规模**：英文评测 31,358（96%）、中文 26,348（95%）；2025-04 同时在线破 **12 万**（GameLook/小米游戏中心报道）；早期媒体报道总评测约 11 万（2026-09）。
- **喜欢**：你打字它就敲键盘——**把工作变成可见反馈**；不弹窗、不抢焦点、资源占用低；免费；帽子的收集/交易价值（报道称饰品分稀有度）。
- **反感**：玩法极浅、很快腻；饰品/交易机制被质疑“像开箱”；对非打字用户价值低。
- **启示**：**“工作行为 → 角色反馈”是最轻的差异化**，famling 的 DSH 工具状态/工作简报可以做得更深；但**不要碰随机饰品/交易**（付费陷阱与赌博风险）。

### 2.11 桌面类补充 C：VPet-Simulator（2023，中文免费+Workshop 基线）

- **形态/分发**：LB Game 2023-08-13 上线 Steam；免费 + Workshop + 3 个 DLC；代码 Apache-2.0（GitHub 7,253★）。
- **规模**：中文评测 43,520（98%）、英文 3,753（95%）；200+ 动画、可内置到 WPF 应用。
- **喜欢**：免费、动画多、创意工坊、可自定义、国产中文、开发者活跃。
- **反感**：偏“模拟器/游戏”，工作场景弱；UI 与性能参差；内容重复；新手引导一般。
- **启示**：**中文用户对“免费 + 创意工坊 + 高动画量”有明确预期**；famling 的像素规范/三形象是差异，但不能在“免费+动画数量”上硬拼。

### 2.12 桌面类补充 D：Rusty's Retirement（2024，屏幕底部 1/3 的场景创新）

- **形态/分发**：Mister Morris Games 2024-04-26 上线；$6.99 买断；只占屏幕底部约 1/3，不挡上方工作区。
- **规模**：英文评测 6,628（97%）、中文 3,625（95%）；2026-04 媒体称累计 1.4 万+评测、97%；有玩家为全成就投入 150+ 小时。
- **喜欢**：不打扰工作、可随时瞄一眼、种田/自动化循环、低价、适合“摸鱼”。
- **反感**：前期手忙脚乱（作物会干死）、后期像“挂机”、硬核玩家嫌内容浅、全成就耗时。
- **启示**：**“屏幕边缘/底部”是比“全覆盖”更友好的桌宠形态**；famling 的小尺寸（72px 插件 / 96×96 桌面）方向正确。

### 2.13 桌面类补充 E：Ropuka's Idle Island（2025，贴纸式低价）

- **形态/分发**：2025-01-29 上线；$3.99 买断；自称“a playable sticker for your desktop”，青蛙在桌面割草/升级/装饰；与 Bottom-Of-Your-Screen 捆绑包。
- **规模**：全部语言评测约 1,256（96%），中文 478（94%）。
- **喜欢**：便宜、极简、可放任意角落、无压力、可爱。
- **反感**：内容少/重复、没有目标感、很快看腻。
- **启示**：**$3.99 是“桌面小玩具”的心理价位**；famling 的独立版若只做“看宠物”，很难卖超过这个档。必须让用户感知到“工作简报/记忆”才配更高价。

### 2.14 桌面类补充 F：Chill with You: Lo-Fi Story（2025，工作陪伴 + 内容）

- **形态/分发**：Nestopi 2025-11-16 上线；$11.99 买断 + 1 个支持者包；桌面侧边陪伴 + 番茄钟/任务 + Lo-fi 剧情。
- **规模**：中文评测 8,729（98%）、英文 1,520（97%，2026-11-14）；评测总数约 1.29 万。
- **喜欢**：桌面陪伴 + 专注工具 + 剧情/角色；比“纯工具”更有情绪价值。
- **反感**：内容量有限、价格偏高、偏“视觉小说/游戏”而非日常工具。
- **启示**：**“工作陪伴”在 $11.99 档已被验证**；famling 的“只读简报 + 三形象”可以切“更轻、更日常”的位置，但需要证明不是“又一个看板娘”。

### 3.3 反用户（anti-persona，明确不服务）

- **想找 AI 女友/男友、角色扮演、情感陪伴的人**：官方不提供、不鼓励；如用户自行接入第三方模型，按 TOS 用户自担（内部法务口径，见 §9）。
- **儿童/家长**：不做儿童向营销、不进 Kids 分类、不投儿童广告；一般功能全年龄可用，但角色扮演仅 18+（内部 2026-11-17.5 决策）。
- **需要第二大脑/任务管理器的人**：重任务留给 Advisers/CLI；桌宠只做只读简报与轻提醒。
- **需要常驻聊天窗/语音常开的人**：不做；输入是“交办条”而非聊天（内部 SECRETARY 定位）。
- **想白嫖全部美术/二创商用的人**：PolyForm NC + CC BY-NC-SA 不允许；商业需书面许可。

|---|---|---|---|

### 5.2 五种留存机制，谁靠什么活

| 机制 | 定义 | 代表 | 衰减风险 | famling 适配 |
|---|---|---|---|---|
| **常驻（presence）** | 打开电脑/工具它就在，提供“存在感” | Shimeji、Bongo Cat、桌面挂件 | 新鲜感 1–2 周后归零，除非有变化 | 高（插件天然常驻） |
| **工具（utility）** | 不用它做事就少点什么 | Rusty's 种田、Spirit City 番茄钟、Wallpaper Engine 壁纸 | 一旦工具被替代就流失 | 中高（Pet Brief/提醒） |
| **关系（relationship）** | 角色“记得我/需要我/回应我” | Finch、Tamagotchi、AI 伴侣 | 伦理/监管/信任风险；断联即负罪 | **低（明确不做）** |
| **收集/装饰（collection）** | 解锁角色/家具/图鉴 | Spirit City、Neko Atsume、Desktop Mate | 内容耗尽、DLC 疲劳 | 中（外观/图鉴可做） |
| **工作场景（workflow）** | 与工作状态/任务绑定 | Bongo Cat（打字）、Spirit City（专注）、famling（DSH 工具状态） | 依赖宿主/集成深度 | **最高（差异化）** |

**判断**：famling 应把留存押在 **常驻 × 工具 × 工作场景** 三条上，把“关系/收集”做成轻量点缀（外观、互动记录），**不要**做关系型留存（每日专属语音、亲密度、付费解锁关系）——那会同时撞上监管、口碑与成本。

### 5.3 口碑的两个反例（必须记住）

1. **Desktop Mate：免费+IP 分发冲得很快，但 61% 好评说明“高价 DLC + 封闭”能把口碑做坏。** VaporLens 2026-05 的 churn 分析把“Overpriced DLC”列为最大风险（16.2%），并点名“无 mod/自定义”。famling 如果做付费，必须避免同样的路径。
2. **Neko Atsume 2：IP 与玩法都在，但热度回落。** 这说明“可爱 + 放置”本身不是护城河；玩家会疲劳。famling 的“只读简报/工作场景”比“更多猫”更有长期价值。

### 5.4 口碑建设动作（低成本）

- **公开 changelog + 版本号一致**（当前 npm 0.0.1 vs 仓库 0.8.2 是口碑硬伤，见 §7.4）。
- **一个可验证的“30 秒看懂”README/GIF**：三形象切换、点击头/身/尾、只读简报、猫狗不发声。
- **DSH 插件页/README 里写清“不是官方、不是 AI 伴侣、不是儿童向”**，减少误装与差评。
- **建立用户反馈入口（Issue/Discord/QQ 群）与卸载理由收集**；不要买评/刷 star（违反平台规则，也会被社区识别）。
- **对差评做“可复现→修复→公开回复”**：桌宠类产品的差评往往集中在安装/性能/兼容，修复一次能救一批。

### 5.5 留存假设与验证闸门（不要当承诺）

| 阶段 | 假设 | 验证方式（本地 opt-in / 小样本） | 通过门槛（建议，非行业基准） |
|---|---|---|---|
| 首启 | 用户 30 秒内看到“活物+能点” | 本地事件：install→首次点击/首次切角色 | ≥60% 首启有点击 |
| D1 | 用户第二天还会打开 DSH/桌面版 | 本地事件：D1 回访（可选导出） | ≥35% |
| D7 | “简报/提醒”带来工具价值 | 本地事件：7 天内至少 1 次看简报/完成回执 | ≥20% |
| D30 | 三形象/外观/互动记录提供变化 | 本地事件：切角色/互动 ≥3 次 | ≥10% |
| 质性 | 用户能说出“它帮我记住了什么” | 5–10 人访谈/日记 | ≥5/10 能举例 |

> 这些数字是**待验证假设**，不是行业基准；n<30 不做显著性结论（沿用内部 `LONGEVITY-AND-RETENTION-2026-11.md` 的方法论）。

### 6.3 famling 建议的商业模式（研究结论，需产品/法务拍板）

1. **插件（dsh-famling）：永久免费。** 它是获客与验证渠道，不是收入来源；避免与 PolyForm NC 冲突（NC 允许个人非商业使用，但商业分发需授权；插件免费可降低摩擦）。
2. **独立版：v1 beta 免费（与内部 D-08 一致）→ 正式版买断 $9.99–12.99。** 理由：Chill with You 已验证 $11.99、Rusty's/Spirit City 在 $7 档；famling 多了“简报/记忆/三形象”，但仍需先证明价值。
3. **只卖外观 DLC（$2.99–4.99）**：衣服/场景/角色皮肤；**不卖**：关系、亲密度、记忆容量、提醒次数、语音解锁、抽卡。
4. **不做订阅**（除非未来有真正的云同步/多端服务，且可随时导出/删除）；**不做广告**；**不做开箱/随机交易**。
5. **许可分层**：代码 PolyForm NC（当前）/ 商业另授权；美术 CC BY-NC-SA 4.0（当前）；**若想发展社区/角色包，建议把“接口/角色数据规范”单独以 MIT/Apache 发布，美术仍 NC**——但这需要用户/法务拍板（当前未决，不能对外说“开源”）。
6. **数据与信任**：承诺“本地优先、无默认遥测、可导出、停运不锁数据”；这既是口碑差异，也是对冲 QQ 宠物停运类信任风险。

### 6.4 上架前最小清单（Steam/移动/插件通用）

- [ ] 非官方声明（不关联 DeepSeek/PerryLink 之外的主体）与 AI 标识（生成图/合成语音/模型对话）。
- [ ] 隐私政策（草案→生效）、数据流披露（聊天经 DSH Host 发往模型供应商）。
- [ ] 年龄口径（一般功能全年龄；roleplay/情感陪伴 18+ 且默认关）与 2h 提醒/危机转介/退出通道。
- [ ] 不宣称未实现能力（记忆写入、Pet Brief 闭环、Steam 版、跨平台）。
- [ ] 截图/GIF/演示视频（30 秒内说清“它是什么/不是什么”）。
- [ ] 版本号/评测/商店页一致；安装包无未清权音频/素材（当前法务 blockers 未清）。

### 7.4 famling 的诚实差距（不回避）

1. **分发资产几乎为零**：GitHub 1★、npm 0.0.1、无商店页、无发行版；竞品已有 10 万–60 万/月 npm 下载与数千 star。
2. **版本漂移**：本地 `dsh-famling` 0.8.2（DETAIL 已描述 0.8.3 的 `says/actions` 数据驱动能力）、公开仓 0.7.5、npm 0.0.1；**用户装到的不是最新版**。插件目录甚至没有 `.git`（架构文档记录“靠手工拷贝同步”）。
3. **许可逆差**：竞品清一色 MIT，famling 是 PolyForm NC + CC BY-NC-SA；这保护商业化，但劝退社区贡献/二次分发。**对外绝不能称“开源”。**
4. **美术是 placeholder**：三套动画包是占位（96×96），不是最终美术；对比 Desktop Mate 的 45 个官方 IP DLC，视觉资产不占优。
5. **Pet Brief 只读且未闭环**：读 `~/.advisers/pet-brief.json`，写记忆/提醒闭环未实现；不能对外说“会记住你”。
6. **DSH 平台风险**：DSH 处于 0.2.x rc，插件 API 多次重命名；`engines.dsh >=0.2.1-rc.5 <0.3.0` 是硬约束；官方若出桌宠/改 slot，famling 需快速适配。
7. **法务/发布未闭环**：16 个 strict blockers、AI 标识未闭环、隐私政策草案、无律师审查；**当前不能做“已发布/已合规”宣传**。
8. **无验证数据**：没有留存/点击/卸载数据；npm 下载量不能当用户数（含 CI/镜像/尝鲜）。

### 10.2 三个最高优先动作（给 lead 的一页版）

**动作 1：把“装得到、装得对、看得懂”修好（P0，1–2 周）**
- 统一 `package.json` / 公开仓 / npm / README / DETAIL 版本；把 npm 从 0.0.1 重发到当前 0.8.x；插件目录入 git + CI（`node --check`、`npm test`、`check:anims`、`verify:anims`、版本一致性）。
- 在 DSH 插件市场/awesome 榜单/README 放 30 秒 GIF + 一行安装；修复公开仓 docs 与本地不一致。
- 验收：新用户从“看到”到“装上并看到宠物”≤3 步；安装失败有可读错误；npm/README 不再出现 0.0.1。

**动作 2：把差异化压缩成 30 秒（P0–P1，2–4 周）**
- 拍 §7.7 脚本：三形象切换 → 分区点击 → 只读简报 → 边界字幕；同时产出 3 张商店级截图（1x/4x 可读）。
- 写“What it is / is not”一页（§8.4），放 README 首屏与设置页；所有渠道统一“非官方/非 AI 伴侣/非儿童向/不卖关系”。
- 验收：不看说明的人能在 30 秒内说出“这是桌面工作搭子、能点、能看简报、不是聊天伴侣”。

**动作 3：用数据决定要不要投美术/Steam（P0–P1，4–8 周）**
- 本地 opt-in 事件（默认关、可导出/删除）：首启点击、切形象、简报打开、D1/D7 回访、卸载理由（可选文本）。
- 小样本 50–100 人（DSH 社区/中文开发者/学生），两周复盘；通过门槛见 §5.5。
- 只有通过 D7/质性门槛，才进入 P1 美术量产与 P2 Steam 页；否则先改首启与价值点。

### 10.4 Kill / pivot 条件（避免自嗨）

- 首启 30 秒内点击率 <40%，或 D7 <10%（小样本）→ 先修首启/价值点，不投美术量产。
- 用户访谈中 >50% 把 famling 描述为“又一个桌宠/看板娘”，说不出“工作简报/秘书”差异 → 定位失败，改文案或改产品。
- 出现“像 AI 女友/会依赖/儿童向”的自然评价 → 立即检查文案与交互，按 §9 整改。
- 分发修复后 30 天 npm 下载仍 <2,000 且无自然增长 → 渠道判断错误，转向 DSH 社区/内容平台或放弃独立发行假设。
