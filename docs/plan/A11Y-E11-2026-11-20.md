## 2. 为什么需要这个门禁

1. 仓库无 jsdom/Playwright，真实布局/焦点/对比度此前没有自动化证据；MB-116 在 `EXECUTION-STATUS-2026-11-20` 中为 **TODO（无 axe/对比度/自动化无障碍测试）**。
2. 代码里已有大量 ARIA/键盘/焦点管理（`desktop-shell.ts`、`content-hub.ts`、`consent/modal.ts`），但**没有东西防止它们回退**：改一个 `replaceChildren` 或 CSS 颜色就可能悄悄丢掉焦点、live region 或 4.5:1 对比度。
3. 真实浏览器才能测到：computedStyle 的实际颜色/字号、真实焦点遍历、`:focus-visible` 轮廓、`inert` 后的可聚焦性、CDP 媒体模拟下的 reduced-motion 实际生效值。
4. 可重复：一条命令 + 结构化 JSON + 截图 + 已知缺口 baseline；新增违规退出码 1，环境问题退出码 2。

## 4. 如何运行

前置：

1. `npm run build` 已构建 `dist/`（脚本会拒绝缺失或**比 src/public 旧**的 dist，避免用过期 bundle 通过门禁）。
2. Node >= 22（全局 `fetch`/`WebSocket`）。
3. 本机 Chrome/Chromium（`--chrome PATH` 或 `CHROME_PATH` 覆盖自动探测）。
4. WSL 需要为 WSL2 mirrored networking（Windows Chrome 与 WSL Node 共享 `127.0.0.1`）；否则请在 Windows 原生运行。

~~~bash
npm run build
node scripts/a11y-cdp-check.mjs                         # 默认 headless=new，自动探测 Chrome
node scripts/a11y-cdp-check.mjs --chrome "C:/Program Files/Google/Chrome/Application/chrome.exe"
node scripts/a11y-cdp-check.mjs --out artifacts/a11y-cdp/my-run --headed --verbose
node scripts/a11y-cdp-check.mjs --help
~~~

- 退出码：`0` 无**新**违规；`1` 有新增违规/回归；`2` 环境/用法错误（找不到 Chrome、dist 缺失/过期、baseline JSON 损坏）。
- 产物：`<out>/report.json` + 6 张 PNG；默认 `artifacts/a11y-cdp/run-<stamp>/`；并复制 `artifacts/a11y-cdp/latest.json`。
- **已知缺口 baseline**：`scripts/a11y-contrast-baseline.json`。匹配规则 = `check + signature`；命中的已知缺口在 report 的 `knownFindings` 中**公开列出但不使门禁变红**；修复了缺口但没刷新 baseline → report 标 `stale`（只提示，不失败）。**新增**违规一律失败。
- **WSL 构建注意（本机实测）**：`npm run build` 若报 `Cannot find native binding @rolldown/binding-linux-x64-gnu`（Windows 侧 node_modules 只有 win32 binding），在 WSL 执行 `npm install --no-save --no-audit @rolldown/binding-linux-x64-gnu@<rolldown 版本>` 补齐 Linux 绑定（不改 package.json/lockfile）。本次已用此方式构建成功。
- CI：**不接入** `npm run ci`（CI 无可信浏览器）；`tests/a11y-cdp-check.test.ts` 断言它不在 `scripts/ci.mjs` 也不在 `package.json` scripts。
- 数据隔离：一次性 Chrome profile（`run-*/profile`，结束/失败都会结束 Chrome 并删除）；静态服务器只读 `dist/`；不读写真实用户 `%APPDATA%`/localStorage。

## 7. 明确不覆盖 / 不得宣称

1. **不是 axe 全规则**：无 axe-core 依赖/无网络，只做 WCAG 2.1 1.4.3（文本对比度）、1.4.11（非文本对比度，用于焦点圈）与针对本产品的 ARIA/焦点/live region/reduced motion 断言。reflow、400% 缩放、屏幕阅读器实际播报、色盲模拟、图片内文字、伪元素文字未覆盖。
2. **渐变/图片背景上的文字**：按规则 skip 并记录数量（本次 statement-page skip 4 个），不猜测；`color(display-p3 …)` 也 skip。
3. **字号口径**：面板通过 CSS transform 缩放（整体缩放），对比度阈值按 computed font-size 判定，属**保守**（取更小字号），不是视觉变换后的实际字号。
4. **reduced-motion 是模拟**：CDP `Emulation.setEmulatedMedia`，不是真实 OS 设置；只验证菜单开/关功能等价，未逐动画验证。
5. **不是 Tauri/WebView2 真机**：托盘、单实例、Rust 退出、真实 760×560 外框、GPU 合成均未跑。
6. **不是视觉验收**：截图只作证据，headless + `--disable-gpu` 不测像素级视觉。
7. **不伪造**：本文与 report 中数字均来自真实运行输出；未验证项一律写「未验证」。`knownFindings` 不会因为「写进 baseline」就被当成已修复。
