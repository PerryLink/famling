## 2. 为什么需要这个 smoke

1. **现有测试不跑真实布局**：仓库无 jsdom/Playwright；`27` 个测试用 `readFileSync` 读 `main.ts` 源码文本，`main.ts`/`setup-page.ts` 至今没有被测试 import（EXECUTION-STATUS 2026-11-20 · MB-110）。
2. **760×560 内容窗口此前只有 commit message 的证据**：`b83b11e` 声称 CDP 实测 760×560，但结果没有归档成 artifact（MB-062 / MB-114 剩余项）；本 smoke 把布局、面板切换和截图落盘。
3. **真实浏览器能测到 fake DOM 测不到的东西**：CSS 变量实际生效值、真实 `window.open` 弹窗生命周期、真实 `Input` 事件（右键、滑杆点击、`Shift+F10`/`Escape`）、刷新后的 hero canvas 是否真的画出像素。
4. **可重复**：一条命令 + 结构化 JSON + 截图；失败时退出码 1，前置不满足退出码 2。

## 4. 如何运行

前置：

1. `npm run build` 已构建 `dist/`（脚本会拒绝缺失或**比 src/public 旧**的 dist，避免用过期 bundle 通过 smoke）。
2. Node ≥ 22（使用全局 `fetch`/`WebSocket`）。
3. 本机 Chrome/Chromium（`--chrome PATH` 或 `CHROME_PATH` 覆盖自动探测）。

~~~bash
npm run build
node scripts/gui-cdp-smoke.mjs                      # 默认 headless=new，自动探测 Chrome
node scripts/gui-cdp-smoke.mjs --chrome "C:/Program Files/Google/Chrome/Application/chrome.exe"
node scripts/gui-cdp-smoke.mjs --out artifacts/gui-smoke/my-run --headed --verbose
node scripts/gui-cdp-smoke.mjs --help
~~~

- 退出码：`0` 全绿；`1` 检查/前置失败；`2` 环境/用法错误（找不到 Chrome、dist 缺失/过期等）。
- 产物：`<out>/report.json` + 7 张 PNG；默认 `artifacts/gui-smoke/run-<stamp>/`；并复制一份到 `artifacts/gui-smoke/latest.json`。
- **WSL（本机形态）**：Node 在 WSL、Chrome 是 Windows 原生；要求 WSL2 **mirrored networking**（Windows/Linux 共享 `127.0.0.1`），否则请直接在 Windows 运行。Chrome 用 `--remote-debugging-port=0` + `DevToolsActivePort` 自动取端口，避开 WSL 端口占用冲突。
- **Windows 原生**：同样命令；脚本用 PowerShell 按 profile 路径精确结束本次 Chrome（不会动用户自己开的 Chrome）。
- **Linux**：安装 `google-chrome`/`chromium` 后可直接运行。
- **CI**：**不接入** `npm run ci`（CI 无可信浏览器）；`tests/gui-cdp-smoke.test.ts` 断言它不在 `scripts/ci.mjs`、也不在 `package.json` scripts 中，避免默认门变成「需要本机浏览器」。
- 数据隔离：Chrome 用 `artifacts/gui-smoke/run-*/profile` 的一次性 profile；启动前按该 profile 路径清理上次残留，结束/失败都会结束 Chrome 并删除 profile；静态服务器只读 `dist/`；不读、不写真实用户 `%APPDATA%`/localStorage。
- 若 `npm run build` 报 `Cannot find native binding`（rolldown/esbuild 的 npm optional deps 已知问题），按仓库常规在**目标平台**执行 `npm ci`（或 `npm install`）补齐平台绑定；本次最终构建在 WSL 成功（`npm run build` → exit 0）。

## 6. 明确不覆盖 / 不得宣称

1. **Tauri 宿主 / WebView2 原生窗口**：托盘、单实例、`skipTaskbar` 宠物窗、Rust `quit_app`、内容窗口的**真实 760×560 外框**与可缩放行为 → 本 smoke 未验证。
2. **退出/保存只覆盖浏览器 fallback**：保存写 WebCrypto localStorage，退出走 save-then-`window.close()`；Tauri 的 save-then-`quit_app` 未跑。
3. **渲染质量**：`headless=new` + `--disable-gpu`，不测 GPU 合成、帧率、真实桌面叠加/点击穿透。
4. **内容窗口尺寸口径**：760×560 是 CDP 视口模拟（产品 Tauri 窗口的内容尺寸口径）；实测同尺寸 `window.open` 弹窗内高为 509（浏览器窗口边框占 51px），因此**不能**据此声称「Chrome 里做出来的窗口就是 760×560 内容尺寸」。
5. **不联网、不碰真实用户数据**：所有页面来自本地 `dist` 静态服务；profile 是一次性目录；不读真实 `%APPDATA%`、不写真实用户 localStorage。
6. **不伪造**：本文与 report 中的数字均来自真实运行输出；没有真机/外部验证的项目一律写「未验证」，不得用本 smoke 替代 Tauri E2E 或发布验收。
7. 视觉细节（例如菜单图标在 headless 截图中尚未加载完的 broken-image 占位）不影响行为断言，也未被当作视觉验收。

## 7. 维护指南

- **改 UI 文案/结构时同步三处**：`scripts/gui-cdp-smoke.mjs`（选择器/根菜单文案/角色按钮）、本文件、`tests/gui-cdp-smoke.test.ts`（场景 id/文档断言）。脚本失败会直接给出缺失的选择器或断言字段。
- **失败排查顺序**：`report.json` 的 `checks[].error/evidence` → `pageDiagnostics`（未捕获异常）→ 同目录截图 → 加 `--verbose` 重跑 → 需要观察浏览器时加 `--headed --keep-profile`。
- **超时/环境**：默认单条件 30s、脚本 watchdog 300s；`--timeout` 可调。WSL 下 DevTools endpoint 不通时先确认 mirrored networking，或改在 Windows 原生运行。
- **保持轻量**：不把真实浏览器塞进 `npm run ci`；不为此改业务代码；新增场景 = `runCheck` + 本文件 + 契约测试。
- **证据归档**：`artifacts/` gitignored，按需保留最近 run；若需要长期证据，在交付/发布流程里显式拷贝 `report.json` 与截图，不要依赖它们自动入库。
