BEFORE YOU USE

先配置你自己的模型与 API Key

桌宠的模型对话、摘要融入、TTS 语音都需要你自己的模型账户。**所有调用会产生费用，由你的账户承担**；不配置时只使用本地行为/字幕/占位能力。

会产生费用：本应用不代付、不赠送额度。模型/语音调用按你的服务商计费；请先了解价格并设置预算。

推荐方式：环境变量

  1. 从模型服务商获取 API Key；不要把它发到聊天、issue、截图或仓库。
  2. 在启动桌宠前设置环境变量（Windows 示例）：
    setx DEEPSEEK_API_KEY "你的 key"
    重新打开应用/终端生效。
  3. 如使用其它 OpenAI-compatible 服务，按项目文档设置对应 base URL/模型；不要混用不明来源的代理。
  4. 打开桌宠，正常摸/拖/说；需要模型的功能会使用你的 key。若没有 key，语音/摘要会降级为本地/字幕。
